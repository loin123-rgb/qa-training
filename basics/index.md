# 第一章 · 基礎

在學任何一個檢驗動作之前,要先有兩個東西:**一張全貌圖**,和**一套共同語言**。

新人最常見的狀況不是不會量測,是聽不懂會議上在講什麼——「這批走特採」「開 CAR 了沒」「MRB 還沒判」。名詞不通,後面全部卡住。

## 為什麼要先看全貌

因為每一關的**目的不同**,判定標準才會不同。

同樣是「尺寸超出公差 0.02 mm」:
- 在**進料**發現 → 退供應商,成本是供應商的。
- 在**製程**發現 → 已經投入工時了,可能重工。
- 在**成品**發現 → 整支報廢,損失最大。
- 到**客戶端**才發現 → 賠償 + 商譽 + 可能被稽核。

同一個缺陷,發現得越晚成本越高。這就是為什麼品保要在前面多擋——**不是為了刁難,是為了讓錯誤停在最便宜的地方**。

新人如果不理解這件事,很容易變成兩種失敗的極端:
- 什麼都放行,想說「後面還會檢查」
- 什麼都擋下來,產線停擺卻講不出理由

## 你應該要會

讀完這一章,你要能:

- [ ] 畫出料件從進廠到出貨會經過哪幾個品質關卡
- [ ] 說出每一關的目的,以及擋不住會發生什麼事
- [ ] 看到 IQC、IPQC、FQC、OQC、MRB、CAR、NCR、AQL、特採 這些字不用問人
- [ ] 解釋為什麼「同一個缺陷,越晚發現越貴」
