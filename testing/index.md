# 第三章 · 成品測試

**目的:確認成品的功能符合規格。**

前面兩關看的是「做得對不對」,這一關看的是「**行不行**」。外觀尺寸全部漂亮,但流量誤差超出限值,一樣是不合格品。

這一章的難度跟前面不同。IQC 大多是「量一個尺寸,比一個公差」,成品測試要理解:

- 為什麼要在**好幾個不同的流量點**測,不是測一次就好
- 為什麼**不同流量點的誤差限不一樣**
- 為什麼調整一個點,**其他點也會跟著動**

## 先建立的觀念

### 一、量測結果是「表 + 設備 + 環境」的總和

你量到的誤差,不只是產品的誤差,還包含:

- 標準器(比對用的基準)本身的誤差
- 試驗台的管路、閥件、溫度、壓力狀態
- 起停過程的暫態
- 讀值與計時的人為誤差

{: .important }
所以測出一個「-2.3%」時,第一個問題不是「這支不良」,而是
**「這個數字可信嗎?」**——設備校正在效期內嗎?條件穩定嗎?其他支也是這樣嗎?

一整批突然全部偏同一個方向,**先懷疑設備,不要先懷疑產品**。

### 二、誤差限是法規要求,不是內部標準

尺寸公差是我們(或客戶)訂的,可以討論。但成品的計量誤差限通常寫在**國家標準或型式認證**裡,那是法定要求——**不能特採、不能通融**。

{: .warning }
計量誤差超出法定 MPE 的產品,**不存在「特採出貨」這個選項**。
這跟外觀刮傷不一樣。新人一定要分清楚哪些項目可以談、哪些不能。

### 三、合格不等於做得好

法規誤差限可能是 ±2%,但如果你們的產品**普遍落在 -1.9%**,那是「勉強及格」——

- 量測不確定度一算進去,可能其實已經超出
- 使用一段時間後性能衰減,很快就會不合格
- 客戶抽驗時只要條件稍有不同就會被判不合格

好的產品應該**集中在零附近**,不是貼著限值。這也是為什麼要談[校正設定點](calibration/)。
