# 第二章 · IQC 進料檢驗

**目的:讓別人做壞的東西,不要進到我們的產線。**

這是你最常做的工作,也是最容易被催的工作——產線在等料,採購在問什麼時候能入庫。壓力之下最容易犯的錯是「看起來還好,先放行」。

這一章要建立的不是「怎麼量」,是**怎麼在有壓力的情況下做出一致的判定**。

## 三個原則

### 一、依規範,不依印象

每一個料號都應該有對應的**檢驗規範**,規定檢哪些項目、用什麼量具、標準是多少。

不要憑「上次好像是這樣」。特別是:
- 同一個品名可能有多個料號,公差不同
- 規範改版後,舊的判定基準就失效了

{: .warning }
拿到檢驗規範第一件事:**確認版次是不是最新的**。

### 二、判定要可重現

同一批料,換一個人來檢,應該得到同樣的結論。做不到的話,你的判定就不是判定,是意見。

可重現的三個條件:
1. 抽樣方式一致(隨機抽,不是挑好的抽,也不是只抽最上層)
2. 量測方法一致(同樣的量具、同樣的位置、同樣的次數)
3. 判定基準一致(查同一份規範、同一個版次)

### 三、記錄要能還原現場

三個月後有客訴回頭追這一批,你的檢驗表要能回答:誰檢的、什麼時候、抽了幾件、量到多少、依據哪一版規範、判定結果、誰核准。

{: .important }
**沒寫下來的等於沒做。**
「我有量,只是沒記」在稽核和客訴追溯時完全站不住腳。

## 常見的壓力情境

新人一定會遇到,先想好怎麼回應:

| 情境 | 錯誤的做法 | 正確的做法 |
|:--|:--|:--|
| 「產線在等,先放行好不好」 | 口頭答應,事後補單 | 說明還需要多久;真的急,走**緊急放行**程序(有紀錄、可追溯、限定範圍) |
| 「上次這樣也過了」 | 比照辦理 | 查上次的紀錄是不是特採。**特採不會自動延續到下一批** |
| 「只差一點點」 | 自己判定可接受 | 超出就是超出。要放行就走特採,由權責決定 |
| 「供應商說沒問題」 | 採信 | 供應商的說法是資訊,不是判定依據。依規範量測 |
| 不確定怎麼判 | 猜一個 | 標記「待判定」,問主管或工程 |

{: .important }
「我不確定,先擋著,我去問」——這句話任何時候說出來都是對的,而且沒有人能怪你。

- [ ] 查抽樣計畫表,得出樣本數與 AC/RE
